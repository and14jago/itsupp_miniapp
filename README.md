# ITSUPP Telegram Mini App (`and14jago/itsupp_miniapp`)

Полнофункциональное Telegram Mini App для `@itsupp_task_bot` с экраном входа **как в Сбере (Face ID / Touch ID + 5-значный код доступа)** и полным рабочим кабинетом задач Okdesk.

## Основные возможности

1. **Экран входа в стиле Сбербанк Онлайн (`ITSUPP ID`)**:
   - Нативная поддержка `Telegram.WebApp.BiometricManager` (`Face ID` / `Touch ID`) + анимированный сканер биометрии и 5-значный ПИН-код с тактильным откликом (`HapticFeedback`).
   - Автоматическое приветствие по времени суток и сопоставление `Telegram.WebApp.initDataUnsafe.user.id` с профилем сотрудника Okdesk.

2. **Полный функционал `@itsupp_task_bot` внутри Mini App**:
   - **Клавиатура главного меню 1-в-1 с ботом**: `Мои задачи`, `Создать задачу`, `Обновить задачи`, `Поиск`, `Оповещение о новых задачах: ВКЛ/ВЫКЛ`, `AI 500`, `Ещё`.
   - **Списки и фильтрация задач (`ASSIGN-ROUTE-DIAG-20261103`)**:
     - В раздел `Мои задачи` попадают строго заявки, где сотрудник является основным `assignee_id` (соисполнители `coexecutors` не дублируются во владельцы).
     - Разделы: `Мои задачи`, `На контроле`, `На сегодня`, `Просроченные`, `Все задачи` + фильтр по статусам и живой поиск.
   - **Ролевые действия по карточке (`WORKING` / `CONTROL` / `OFA`)**:
     - Смена статусов (`Принял`, `Выполняю`, `Отложить`, `Передать задачу`, `Решена`, `На доработку`, `Отклонить`).
     - Калькулятор списания времени (`-5м`/`+5м`, `-10м`/`+10м`, `-15м`/`+15м`, `-30м`/`+30м`, `-2ч`/`+2ч`, `-4ч`/`+4ч`, тарифы: `Обычная`, `Переработка`, `Вне договора`).
     - Быстрое закрытие в 1 клик (`⚡ Закрыть в один клик, списать 15 минут`).
     - Меню переноса сроков (`Завтра 10:00 · +5 мин`, `Послезавтра 10:00 · +5 мин`, `Через 7 дней 10:00 · +5 мин`, `+20/+40/+60 мин`).
     - Делегирование с постановкой на контроль (`CONTROL`), напоминание исполнителю (с защитой 45 сек), комментарии, переход в Okdesk и в чат `@itsupp_task_bot`.
   - **Мастер создания задачи (`create_task.py`)**:
     - Направление (`Техническая поддержка` / `В бухгалтерию`), поиск по всем **130 активным компаниям** из `companies_active.csv`, объект обслуживания, описание и вложения (до 5 файлов), выбор исполнителя из каталога сотрудников Okdesk, пресеты времени (`5`–`60` мин).
   - **Голосовой ассистент `AI 500`**:
     - Голосовой ввод (Web Speech API) и автоматический NLP-разбор текста заявки (клиент, направление, исполнитель, трудозатраты, описание).
   - **Результаты, Статус системы, Дежурный и Безопасность**:
     - Личный KPI (`Мой результат`), сводка по отделу (`Все сотрудники`), `Статус системы`, выбор дежурного сотрудника (`Дежурный`), настройки биометрии и смена 5-значного кода.
